# 축전기 서비스 센터 — 축전기의 원리와 활용 3D 시뮬레이션

비상교육 고등학교 『물리학』 **Ⅱ. 전기와 자기 › 03. 축전기와 센서** (교과서 82~85쪽) 단원을 위한
체험·조작 게임형 3D 교육 시뮬레이션입니다.

- **성취기준** [12물리02-03] 축전기에서 전기 에너지를 저장하는 원리가 각종 센서와 전기 신호 입력 장치 등
  실생활 제품에서 활용됨을 설명할 수 있다.
- 학생은 「축전기 서비스 센터」의 견습 엔지니어가 되어 수리 미션을 해결하며 축전기의 원리를 익힙니다.
- 교육과정 지침에 따라 '전기 용량'이라는 용어·수식 없이 **«충전되는 전하의 양»** 으로 서술합니다.

## 실행 방법

**바로 실행** — `index.html` 을 브라우저(Chrome/Edge)로 열면 됩니다. 별도 설치가 필요 없습니다.
(3D 엔진 Babylon.js 는 CDN 에서 불러오므로 인터넷 연결이 필요합니다.)

GitHub Pages 로 배포하면 링크로 바로 접속할 수 있습니다:
저장소 **Settings → Pages → Branch: `main` / `(root)`** 선택.

## 구성 (탭 3개 = 3차시)

| 탭 | 내용 |
|---|---|
| **① 충전과 방전** | 전지·칼날 스위치·축전기·LED 소켓을 클릭·드래그로 배치해 회로를 완성. 충전·방전 시 전하 입자가 도선을 따라 이동하고, 판 사이에 전기장(전기력선)이 나타난다. 용량(470/1000/2200μF)을 바꾸면 판 크기·간격·유전체가 변하고 Q=CV 만큼 전하가 쌓인다. LED를 거꾸로 끼우면(뽑아 돌려 끼우는 애니메이션) 방전되지 않는다. |
| **② 축전기의 구조** | 원통형 축전기를 클릭으로 5단계 분해 — 껍질 벗겨 옆에 두기 → 꺼내어 눕히기 → 축과 나란히 펼치기(약 1.2 m) → 금속판·절연체 3층 분리. 조립 모드에서는 전원 회로에 연결된 평행판의 간격·면적을 조절하며 도선을 따라 드나드는 전하와 전하량 게이지를 관찰하고, 목표 전하량 라운드 3종을 수행한다(마지막은 분해의 역재생처럼 말아 원통 만들기). |
| **③ 생활 속 축전기** | 자동 심장 충격기(배터리→고전압 변환 회로→축전기→패드→심장, 인체 모형 충격 모션)·카메라 플래시(전지→승압 회로→축전기→크세논 방전관)·터치스크린(다이얼 번호판 터치 → 그 지점만 전하가 빠졌다가 복원, 층 벌려 보기)·습도 센서(공기·흡습층 수분 평형)를 점검하고, 실물 미니어처를 끌어서 «충전·방전 이용 / 전하량 변화 이용» 두 선반에 분류하면 인증서 획득. |

각 화면 옆의 액자에는 교과서 82~85쪽의 실제 그림·사진이 걸려 있습니다.

## 폴더 구조

```
index.html          실행 파일 (탭 3개 부트스트랩)
js/                 씬 3종 + 학습 콘텐츠(도움말·퀴즈·탐구 단계)
common/             공용 셸(3D 배치·패널·그래프·기록표), 스타일, 아이콘
assets/             교과서 그림 (base64 내장 + jpg)
```
